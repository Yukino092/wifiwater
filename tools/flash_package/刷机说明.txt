========================================
 鱼缸管家 Wifitry - 刷机说明
========================================

【这个包是干什么的】
把新固件刷进设备，修复补水泵/水位控制等问题。

【需要准备什么】
1. 一台 Windows 10/11 电脑（64 位）
2. 一根 USB 数据线（能传数据的，不是纯充电线）
3. 设备（刷机时请拔掉麦克风，USB 和麦克风不能同时接）

【怎么刷】
1. 用 USB 数据线把设备连到电脑，并拔掉麦克风；
2. 双击运行「刷机.bat」（窗口里是英文提示，对照下面）：
      Press any key to start flashing...   -> 按任意键开始
      FLASH OK !                           -> 刷机成功
      FLASH FAILED                         -> 刷机失败（见下文排查）
3. 等到出现 "FLASH OK !"（约 30 秒），设备会自动重启。

【如果提示自动识别串口失败】
脚本会让你输入串口号（COM port），查看方法：
  右键「此电脑」->「管理」->「设备管理器」->「端口(COM 和 LPT)」
  找到类似「USB 串行设备 (COM5)」的条目，把 COM5 输入进去回车。

【刷完之后怎么验证】
设备重启约 30 秒后，对着它说一句：「播报水质」。
如果它能念出水质数据（pH、水温等），说明刷好了。

【常见问题】
Q: 设备管理器里找不到 COM 口？
A: 换一根 USB 数据线（很多线只能充电不能传数据）。

Q: 双击刷机.bat 窗口一闪就没了？
A: 说明解压不完整（缺文件），请完整解压 zip 后再运行。

Q: 杀毒软件报警 / Windows 提示"已阻止"？
A: 这是 esptool.exe 被误报，请点「仍要运行」或把整个文件夹加入信任名单。

Q: 刷到一半断了？
A: 直接重新双击「刷机.bat」再刷一次即可，不会刷坏。

Q: 刷完连不上 WiFi？
A: 确认现场 WiFi 名称/密码与固件 secrets.h 中配置的一致，且为 2.4GHz 频段（ESP32-S3 不支持 5G）。

【刷机不会丢失的内容】
- WiFi 配置（不用重新配网）
- 小智激活信息（不用重新绑定 xiaozhi.me）
- pH 校准值（不用重新校准）
- 本地语音包（语音播报照常）
